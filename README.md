# 🐍 Python Practice Roadmap

A structured roadmap for learning **Python from Basics to Advanced**, with regular coding practice and mini-projects.

> **Goal:** Learn Python by writing code, solving problems, and building projects.

---

## 📚 Level 1 — Python Basics

### Topics

* Variables
* Data Types
* Input / Output
* Operators
* `if / elif / else`
* `for` loop
* `while` loop
* `break / continue / pass`

### 🏋️ Practice — 30–40 Questions

Practice problems:

* Even / Odd
* Positive / Negative
* Largest of numbers
* Calculator
* Grade system
* Multiplication table
* Number guessing
* Factorial
* Prime number
* Fibonacci

---

## 🗂️ Level 2 — Data Structures

### Topics

* String
* List
* Tuple
* Set
* Dictionary
* Indexing & Slicing
* String Methods
* List Methods
* Dictionary Methods

### 🏋️ Practice — 40–50 Questions

Focus on:

* Add / Remove data
* Search
* Count
* Sort
* Reverse
* Remove duplicates
* Maximum / Minimum
* Frequency counting

---

## ⚙️ Level 3 — Functions

### Topics

* Functions
* Parameters
* Arguments
* `return`
* Default Arguments
* `*args`
* `**kwargs`
* Lambda Functions
* Recursion

### 🏋️ Practice — 20–30 Questions

Focus on writing reusable functions and solving problems using functions.

---

## 🚀 Level 4 — Intermediate Python

### Topics

* List Comprehension
* Dictionary Comprehension
* Set Comprehension
* `map()`
* `filter()`
* `reduce()`
* `zip()`
* `enumerate()`
* Modules
* Packages
* File Handling
* Exception Handling

> 💡 **From this level, start building real programs.**

---

## 🏗️ Level 5 — Object-Oriented Programming (OOP)

### Topics

* Class
* Object
* Constructor
* Methods
* `self`
* Inheritance
* Encapsulation
* Polymorphism
* Abstraction
* `super()`

### 💻 Projects

* Student Management System
* Bank Management System
* Library Management System
* Employee Management System

---

## 🔥 Level 6 — Advanced Python

### Topics

* Iterators
* Generators
* Decorators
* Context Managers
* Regular Expressions
* Type Hints
* Dataclasses
* JSON
* APIs
* Database
* Multithreading
* Async Python
